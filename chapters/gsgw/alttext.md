# Alt Text — Word Replacements

# A "## Heading" becomes one group in the reader's Alt Text modal.
# Second line (optional): short description shown in parentheses.
# Format: before1, before2 -> after1, after2
# Left side: words/phrases to find (all get replaced)
# Right side: options the user can pick from

# So for example:
# ## Soleum
# Soleum, Soleum2 -> Soreum, Soreum2
# (short description you want to give this alt text, optional)
